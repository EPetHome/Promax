# Promax 固定桌面界面改版

已修改桌面项目 `/Users/Admin/Desktop/Promax/promax-ui`，并安装到本机运行环境。浏览地址：http://127.0.0.1:3080/。

## 布局与交互

- 左栏 240px、右栏 304px；中间至少 640px。侧栏只接受手动收起，收起后分别为 64px、44px。
- 窗口低于 1184px 且两栏展开时出现横向滚动，不缩字、不自动隐藏侧栏。
- 顶栏 56px，页签 44px，任务输入区 106px；常用按钮 34px 且文字单行。
- 新需求、工作台、任务轨迹、交付物共用固定框架。新需求的最近产出占现有右栏。
- 移除大圆角外框、渐变和装饰光晕；交付物与成员采用列表，状态读取失败时不显示虚假 0%。
- 原生会话保留挂载；只有任务轨迹页可访问该内容，其他页隐藏其视觉和键盘入口。刷新已选任务时恢复原生会话。
- 保留原有规划、自动开始倒计时、停止、附件、审核与打开文件夹逻辑。

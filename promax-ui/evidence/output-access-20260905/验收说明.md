# 项目目录与本次产物入口

- 左栏每个展开项目下提供“打开项目目录”，打开对应项目根目录。
- 右栏置顶固定 240px 的“本次产物”卡片；文件列表内部滚动，提供文件查看、查看全部、打开产物目录。
- 中间页签显示“本次产物 · 数量”；文件名可以点击，Markdown 支持标题、正文、表格预览，文本文件显示正文。预览可返回列表。
- 2 MiB 以上文件及其他格式通过产物目录使用本机应用查看；不执行产物中的脚本。
- 保持 240px 左栏、304px 右栏，原智能体两列与 220px 卡片高度。

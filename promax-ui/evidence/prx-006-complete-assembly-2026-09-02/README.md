# PRX-006 实现会话证据索引

本目录只记录公开或脱敏的机械检查结果，不含模型、飞书、DeepSeek 或其他凭据值，也不替代负责人的端到端人验。

- `module-tests.md`：任务文件规定的 Agent、GUI 模块命令与静态范围检查。
- `skills-and-personas.md`：28 个原版 Skill 递归差异结果、数量和 7 份 persona 独立报告索引；逐角色报告为本目录下 7 个 `*-persona.md` 文件。
- `fixed-preset-install.md`：固定 preset、首次全量归档、安装态与旧会话影响。
- `web-judge-telemetry.md`：联网证据闭环、Judge 边界与 telemetry hook 限制。
- `settings-mcp-credentials.md`：设置页、MCP 降级模式、飞书官方配置与凭据安全。
- `runtime-smoke.md`：一次性 3080/3090/3100 启动冒烟。
- `human-verification-index.md`：明确留给负责人的真实环境检查项；本会话未勾选人验项。

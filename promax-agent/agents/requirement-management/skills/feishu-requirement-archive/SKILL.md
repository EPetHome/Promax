# 飞书需求归档统计

## 0. 边界

只读取不可变输入清单与用户明确提供的 Base URL。所有调用必须经成员专属 `promax_lark_cli` 网关（内部固定 CLI 1.0.92）；只读解析 URL、表格、字段与记录。归档在本阶段仅表示“统计报告”，不代表删除、移动、改状态或创建归档表。

## 1. 数据与证据

来源编号 `SRC-*`、字段/记录证据编号 `E-*`。记录 Base token、table id、字段映射、读取时间窗、时区、分页完整性和原始数据 SHA256。缺少状态变更历史时，不得用当前状态推断“本周转出”。

## 2. 固定输出

`requirement_management.md` 中固定含：0. 输入与读取版本；1. 字段映射；2. 数据完整性；3. 本期新增已上线；4. 本期新增转出；5. 累计状态；6. 模块分布；7. 边界真值表；8. 无法计算项；9. 外部动作清单；10. 证据追溯矩阵。

## 3. 边界真值表

对时间窗起止、状态枚举、空时间、分页总数逐项做三点代入。当前快照不能证明历史变化时结论为“未提供变更历史，无法计算”，不能以创建时间替代。

## 4. 逐项自检

- `RM-15` 全部读取命令风险级别为 read。
- `RM-16` 时间窗与时区明确。
- `RM-17` 新增与累计没有混淆。
- `RM-18` 状态历史不足时未伪算。
- `RM-19` 没有飞书写入/删除/移动。
- `RM-20` 每个统计可定位到 E-*。

遥测只由运行时 hook 产生，本 Skill 不调用 telemetry Skill，也不写凭据。

# 看板设计规范

> 用户之声 / 核心指标看板的统一设计规范。覆盖布局、色彩、图表选型、无障碍与交互设计，保证所有输出看板的专业性与一致性。

## 一、布局原则

### 1.1 F 型浏览模式

用户视线遵循 F 型路径，关键信息置于顶部与左侧：

```
┌─────────────────────────────────────────────────┐
│ ① 顶部栏：标题 + 时间筛选 + 全局预警状态         │  ← 第一横线
├─────────────────────────────────────────────────┤
│ ② KPI 卡片行（4~5 张）                          │  ← 第二横线
├─────────┬─────────┬─────────┬───────────────────┤
│ ③ 主图  │ ③ 主图  │ ④ 辅助图 │                    │  ← 垂直扫描
├─────────┴─────────┴─────────┴───────────────────┤
│ ⑤ 明细表 / 次要图表                              │
└─────────────────────────────────────────────────┘
```

- 最重要的 KPI 与图表置于左上区域（热区）。
- 阅读顺序：顶部 → 左 → 右 → 下。

### 1.2 卡片式设计

- 每个主题一个卡片，卡片间 16px 间距；结构为「标题 + 指标值 + 趋势徽标 + 图表」。
- 圆角 8px~12px；阴影 `0 2px 8px rgba(0,0,0,0.06)`；悬停轻微上浮 + 阴影加深。

### 1.3 响应式布局

| 断点 | 布局 |
|------|------|
| ≥ 1440px | 12 列栅格，KPI 4~6 列 |
| 1024~1439px | 8 列栅格，KPI 4 列 |
| 768~1023px | 6 列栅格，KPI 2~3 列，主图纵向排列 |
| < 768px | 单列堆叠，KPI 横向滚动 |

## 三、图表选型指南

| 分析场景 | 推荐图表 | 不推荐 |
|----------|----------|--------|
| 时间趋势（DAU/容量） | 折线图 / 面积图 | 柱状图（点多时） |
| 分类对比（渠道/版本） | 横向条形图 | 饼图（>6 项时） |
| 构成占比（<6 项） | 环形图 / 饼图 | 堆叠柱（占比更直观时） |
| 痛点 Top N 排行 | 横向条形图 + 数值标签 | 折线图 |
| 情感分布 | 堆叠面积图 / 环形图 | 散点图 |
| 版本对比 | 分组柱状图 | 雷达图 |
| 相关性（容量 vs 用户量） | 散点图 + 趋势线 | 饼图 |
| 明细数据 | 表格（可排序/筛选） | 图表 |

### 图表规范要点

1. **折线图**：≤ 4 条线；> 4 条拆分为小倍数图（small multiples）。
2. **坐标轴**：柱状图 Y 轴从 0 开始；折线图可截断但需标注。
3. **数据标签**：关键点标注值，避免全标导致拥挤。
4. **空态处理**：无数据时显示引导文案，不渲染空图表。
5. **时间轴**：X 轴统一自然日，缺失日期补齐为 0 或标灰。

## 四、无障碍设计（A11y）

### 4.1 色彩无障碍

- 正文与背景对比度 ≥ 4.5:1；大字号 ≥ 3:1。
- 语义色同时使用**形状/图标/文字**辅助，不单靠颜色区分。
- 红绿色盲友好：避免红绿并排作为唯一区分手段。

### 4.2 文本与字号

| 元素 | 字号/字重 | 说明 |
|------|-----------|------|
| 看板标题 | 20px / 600 | 页面级 |
| 卡片标题 | 14px / 600 | 卡片级 |
| KPI 数值 | 28px / 700 | 用 tabular-nums 防跳动 |
| 图表标签 | 12px | 最小值 |
| 辅助说明 | 12px / 400 | 灰色 |

### 4.3 其他

- 图例完整标注，图表自带标题与单位。
- 支持键盘导航（Tab 遍历图表与筛选器）。
- 动效克制：仅 hover/过渡使用，不加循环动画。
- 打印友好：深色图表打印时自动转浅色。

## 五、交互特性

### 5.1 Tooltip（提示框）

- 悬停显示：数值 + 同比/环比 + 异常标记。
- 格式：`{日期}｜{指标}: {值} ({变化}%)`。
- 异常点 tooltip 额外显示规则命中证据。

### 5.2 筛选器（Filter）

| 筛选维度 | 类型 | 说明 |
|----------|------|------|
| 时间范围 | 日期选择器 + 快捷项 | 今日/近7日/近30日/自定义 |
| 渠道 | 多选下拉 | 应用商店/客服/社群/问卷 |
| 版本 | 多选下拉 | 按版本号过滤 |
| 指标 | Tab 切换 | DAU/容量/渗透率等 |

- 所有图表联动响应筛选，顶部时间筛选为全局状态。

### 5.3 钻取（Drill-down）

```
概览层 → 明细层 → 记录层
DAU 趋势 → 分渠道柱状 → 单条评论/记录
痛点 Top → 领域分布 → 原始评论列表
```

- 点击图表元素进入下一层；明细表支持排序、分页、导出 CSV。
- 提供「返回」面包屑与层级指示。

### 5.4 预警联动

- 命中预警规则的指标显示警示徽标（🔴/🟡/💡）。
- 点击徽标弹出预警详情卡片（规则、证据、处置状态）。
- 看板顶部提供「全部预警」汇总条。

## 六、看板模板结构

```
顶部栏：标题 + 生成时间 + 全局筛选 + 预警状态汇总（🔴/🟡/💡 计数）
KPI 行（4~5 张）：当前值 + 环比 + 趋势迷你图 + 异常标记 + 同比
图表区：主图1 核心指标趋势（DAU/容量）；主图2 情感分布趋势（堆叠面积）
        辅助图1 痛点 Top 10（条形）；辅助图2 量价背离状态（散点/组合）
        明细表 最近 N 条高优反馈
底部：数据说明 + 口径注释 + 导出按钮
```

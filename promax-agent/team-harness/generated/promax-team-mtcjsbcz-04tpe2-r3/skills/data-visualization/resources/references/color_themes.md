# 配色方案

> 看板与图表的标准配色体系。包含语义色、品牌色、数据系列色板、暗黑模式适配与色盲友好方案。

---

## 一、语义色（Semantic Colors）

用于表达状态与情感方向的语义色彩，**含义全局统一，不可挪用**。

| 语义 | 名称 | HEX | 浅色背景 HEX | 使用场景 |
|------|------|-----|--------------|----------|
| 正向 / 成功 | 翠绿 | `#52C41A` | `#F6FFED` | 指标上涨、正面评价、健康状态 |
| 负向 / 危险 | 亮红 | `#F5222D` | `#FFF1F0` | 指标暴跌、负面爆发、严重预警 |
| 警告 | 琥珀橙 | `#FAAD14` | `#FFFBE6` | 接近阈值、警告预警、需关注 |
| 信息 | 品牌蓝 | `#1677FF` | `#E6F4FF` | 中性信息、提示、辅助数据 |
| 中性 | 灰 | `#8C8C8C` | `#F5F5F5` | 基线、历史均值、无意义数据 |

### 语义色使用规则

- 同一看板中红色仅用于「负向」，绿色仅用于「正向」，禁止互换。
- 预警等级与语义色映射：🔴 严重 → 红，🟡 警告 → 橙，💡 关注 → 蓝。
- 表格中的涨跌色遵循中国习惯：**涨=红，跌=绿**（金融场景）或**涨=绿，跌=红**（业务监控），需在配置中显式声明并全站统一。

## 三、数据系列色板（Data Series Palette）

用于多系列图表（多指标、多版本、多渠道对比），按顺序取色。

### 主色板（8 色）

| 序号 | HEX | 名称 | 适用 |
|------|-----|------|------|
| 1 | `#1677FF` | 品牌蓝 | 主指标（DAU） |
| 2 | `#52C41A` | 翠绿 | 正向指标（上传容量） |
| 3 | `#FAAD14` | 琥珀橙 | 次要指标 |
| 4 | `#F5222D` | 亮红 | 负向指标 |
| 5 | `#722ED1` | 靛紫 | 辅助系列 |
| 6 | `#13C2C2` | 青蓝 | 辅助系列 |
| 7 | `#EB2F96` | 品红 | 辅助系列 |
| 8 | `#FA8C16` | 亮橙 | 辅助系列 |

### 使用规则

1. **系列 ≤ 4** 时：取 1~4 号色，语义优先（正=绿、负=红）。
2. **系列 ≤ 8** 时：按 1~8 顺序取色。
3. **系列 > 8**：切换为「同色系不同明度」阶梯（如 8 级蓝），或分组。
4. **同指标多版本对比**：主版本用 1 号色实线，历史版本用同色系浅色虚线。
5. **色盲安全**：若目标用户包含色盲人群，启用第五节替代方案。

### 色板 CSS 变量示例

```css
:root {
  --series-1: #1677FF; --series-2: #52C41A; --series-3: #FAAD14;
  --series-4: #F5222D; --series-5: #722ED1; --series-6: #13C2C2;
  --series-7: #EB2F96; --series-8: #FA8C16;
  --positive: #52C41A; --negative: #F5222D;
  --warning: #FAAD14; --info: #1677FF; --neutral: #8C8C8C;
}
```

## 四、暗黑模式适配

### 4.1 背景层级

| 层级 | 浅色模式 | 深色模式 |
|------|----------|----------|
| 页面背景 | `#F5F7FA` | `#141414` |
| 卡片背景 | `#FFFFFF` | `#1F1F1F` |
| 卡片浮起 | `#FFFFFF` + 阴影 | `#262626` |
| 边框 | `#E5E6EB` | `#303030` |
| 文字主 | `#1F2329` | `#FFFFFF` |
| 文字次 | `#646A73` | `#A6A6A6` |

### 4.2 图表适配

| 元素 | 浅色模式 | 深色模式 |
|------|----------|----------|
| 网格线 | `#F0F0F0` | `#2E2E2E` |
| 坐标轴文字 | `#646A73` | `#A6A6A6` |
| 数据系列 | 主色板原色 | 亮度提升 +15%（`filter: brightness(1.15)`） |
| 语义色 | 原色 | 亮红→`#FF4D4F`，翠绿→`#73D13D` |
| 提示框 | 白底黑字 | `#262626` 底白字 |

### 4.3 实现建议

- 使用 CSS 变量驱动，`prefers-color-scheme: dark` 自动切换。
- 图表库（ECharts 等）配置 `theme: 'dark'` 或手动注入背景色 `transparent` 跟随容器。
- 避免在深色背景上使用大面积的纯黑文字或纯白图形。

## 五、色盲友好替代方案

### 5.1 红绿色盲（最普遍）

红绿并排无法区分时，使用替代组合：

| 原组合 | 色盲友好替代 |
|--------|--------------|
| 红 `#F5222D` vs 绿 `#52C41A` | 橙 `#FA8C16` vs 蓝 `#1677FF` |
| 红 vs 绿（线图） | 红实线 vs 蓝虚线 + 图形标记（三角/圆点） |
| 红 vs 绿（柱图） | 双色 + 斜纹/纯色填充区分 |

### 5.2 全色盲（灰度）

- 依赖亮度与形状区分：`#1677FF`(暗) vs `#FAAD14`(亮)。
- 每个系列配形状标记（○△□◆）。

### 5.3 色盲测试专用色板（6 色）

```
#0072B2  #D55E00  #009E73  #CC79A7  #56B4E9  #E69F00
```

> 该色板基于 Okabe-Ito 色盲安全方案，两两可区分。

### 5.4 保障措施

- 任何预警状态必须「颜色 + 图标 + 文字」三重表达。
- 图表提供图例标识形状，不只靠颜色。
- 上线前使用色盲模拟滤镜（如 `chrome devtools` 色觉缺陷模拟）自查。

## 六、配色检查清单

- [ ] 语义色含义全局一致（正=绿、负=红、警=橙、信=蓝）。
- [ ] 系列 ≤ 8 色，按主色板顺序取值。
- [ ] 对比度达标（正文 ≥ 4.5:1）。
- [ ] 暗黑模式下语义色亮度已调整，无刺眼纯色。
- [ ] 预警状态不依赖单一颜色表达。
- [ ] 深色模式/色盲方案已有对应的 CSS 变量覆盖。

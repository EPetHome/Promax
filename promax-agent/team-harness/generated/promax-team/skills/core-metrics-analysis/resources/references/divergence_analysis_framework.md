# 量价背离分析框架

> 「量」指用户规模（DAU/MAU、活跃用户数），「价」指价值产出（上传/下载容量、付费、创作内容量）。量价背离是发现**结构性用户问题**的核心分析框架。

## 一、背离类型总览

| 类型 | 用户量 | 容量/价值 | 健康度 | 典型含义 |
|------|--------|-----------|--------|----------|
| user_up_capacity_down | ↑ | ↓ | ⚠️ 不健康 | 水货用户（低质量用户拉量） |
| user_down_capacity_up | ↓ | ↑ | ⚠️ 不健康 | 大户依赖（过度依赖头部用户） |
| significant_divergence | 剧烈 | 剧烈 | 🔴 异常 | 数据打架，立即排查 |
| normal | → / 同步 | → / 同步 | ✅ 健康 | 量价同涨同跌，正常 |

## 二、user_up_capacity_down：水货用户

### 2.1 检测标准

| 指标 | 阈值 |
|------|------|
| 用户量增幅（DAU 环比） | +10% 及以上 |
| 价值量变化（上传/下载容量环比） | -15% 及以上 |
| 同周期 | 同一统计窗口（日/周） |
| 情感校验 | 负面评论无显著上升（剔除体验劣化干扰） |

### 2.2 诊断逻辑

```
用户涨 + 容量跌
    ├─ 新增用户画像：是否集中在低价值渠道？
    │     ├─ 拉新活动带来「薅羊毛」用户 → 水货确认
    │     └─ 老用户活跃度下降？ → 留存问题
    ├─ 内容侧：上传内容类型是否变化（低质内容占比上升）？
    ├─ 产品侧：是否弱化了上传引导入口？
    └─ 渠道侧：买量渠道质量下滑？
```

### 2.3 风险评估

| 风险项 | 说明 |
|--------|------|
| 指标失真 | DAU 虚高掩盖真实价值增长停滞，误导决策 |
| 资源浪费 | 增长预算花在低价值用户上 |
| 生态恶化 | 低质内容涌入拉低整体质量，伤及核心用户 |
| 治理成本 | 后续需投入反作弊与内容治理 |

### 2.4 建议动作

1. **渠道归因**：按渠道拆分新增 DAU 与容量贡献，砍掉高成本低产出渠道。
2. **画像与策略**：对比新增/老用户活跃度，拉新从「量」导向转向「有效用户」导向。
3. **治理与指标**：对水货行为上线风控，新增「有效用户占比」「人均上传容量」监测。

## 三、user_down_capacity_up：大户依赖

### 3.1 检测标准

| 指标 | 阈值 |
|------|------|
| 用户量降幅（DAU 环比） | -10% 及以上 |
| 价值量增幅（上传/下载容量环比） | +15% 及以上 |
| 同周期 | 同一统计窗口 |

### 3.2 诊断逻辑

```
用户跌 + 容量涨
    ├─ 头部用户贡献：Top 1% 用户容量占比是否 > 50%？
    │     ├─ 是 → 大户依赖确认
    │     └─ 否 → 检查统计口径是否有误
    ├─ 流失人群：流失的是否为低价值长尾用户？→ 可能反而「假健康」
    ├─ 事件驱动：头部 KOL 集中发布（大促/事件）导致容量脉冲？
    └─ 结构性：容量集中在少数头部，抗风险能力弱
```

### 3.3 风险评估

| 风险项 | 说明 |
|--------|------|
| 尾部空心化 | 长尾用户持续流失，用户结构失衡 |
| 头部风险 | 头部用户流失将导致容量断崖式下跌 |
| 增长假象 | 总量增长掩盖用户活跃度下滑 |
| 商业脆弱 | 收入/容量依赖少数付费方，议价能力弱 |

### 3.4 建议动作

1. **计算集中度**：输出 Top 1% / Top 10% 用户容量占比及变化趋势。
2. **激活腰部**：针对中腰部用户设计任务体系/创作扶持激励。
3. **头部预案与验证**：建立头部流失预警机制，剔除头部重算总量评估真实健康度。

## 四、significant_divergence：显著背离

### 4.1 检测标准

出现以下任一组合即判定为显著背离，直接进入根因排查：

| 条件 | 阈值 |
|------|------|
| 用户量波动 | 单日 ±15% 以上 |
| 价值量反向波动 | 反向 ±20% 以上 |
| 时间窗口 | 连续 ≥ 2 日 |
| 或 | 统计口径/埋点变更、服务故障、数据延迟 |

### 4.2 排查清单

1. **数据口径**：埋点是否变更？统计脚本是否出错？数据是否有缺口？
2. **服务故障**：上传/下载链路是否有 P0 故障（看成功率指标）。
3. **版本影响**：新版本是否修改了埋点或功能路径。
4. **外部与验证**：竞品事故/政策/节假日错位；用两套独立口径交叉验证。

## 五、normal：健康基线

| 特征 | 说明 |
|------|------|
| 量价同向 | 用户量与容量同涨同跌，幅度相近（±5% 内） |
| 相对稳定 | 波动在 2σ 范围内 |
| 结构健康 | Top 10% 用户容量占比稳定，长尾贡献平稳 |

正常态仍需关注微妙的分化趋势：连续 4 周量价增速差 > 3% 时提示「潜在背离」，转入观察名单。

## 六、与情感数据交叉验证

量价背离分析必须结合舆情数据，避免误判：

| 场景 | 交叉验证方式 |
|------|--------------|
| 用户涨+容量跌+负面涨 | 体验劣化导致，非「水货」结论，优先处理体验问题 |
| 用户涨+容量跌+负面平稳 | 确认水货用户/内容质量假设成立 |
| 用户跌+容量涨+负面跌 | 剔除低质长尾后的「假健康」，观察是否可持续 |
| 显著背离+负面爆发 | 高度怀疑服务故障，优先查技术侧 |
| 量价背离+评分下滑 | 双重验证成立，直接触发 🔴 预警 |

### 交叉验证流程

```
量价背离信号
    ├─ 拉取同周期情感指标（负面占比 / 情感分 / 星级均分）
    ├─ 拉取同周期痛点榜单 Top 5
    ├─ 判断情感方向与量价方向是否一致
    ├─ 一致 → 归因成立，输出诊断结论
    └─ 不一致 → 重新假设，优先排查数据口径
```

### 结论输出格式

```
背离类型：user_up_capacity_down
量：DAU +18%（环比），价：上传容量 -16%（环比）
情感校验：负面占比 12%（平稳），无体验劣化信号
归因：拉新活动带来低价值渠道用户
建议：调整渠道预算，上线有效用户指标
```

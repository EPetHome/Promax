# 业务流程图：附件导入进度提示

配套成果（同一套规则编号与状态名称，逐字一致）：

- PRD：`交付/PRD-附件导入进度提示.md`
- 单文件 HTML 原型：`交付/原型-附件导入进度提示.html`

**规则编号**：R-01 支持范围、R-02 批次、R-03 进度口径、R-04 取消、R-05 容量判断、R-06 解析失败、R-07 失败文件暂存、R-08 批次内去重、R-09 索引联动

**批次状态**：排队中、导入中、部分失败、已完成、容量不足、已取消

**文件状态**：排队、解析中、已完成、失败、已取消、索引中

**关键数字（逐字来自附件）**：PDF、PNG、JPG、MP3、M4A；单文件 ≤ 100MB；单批次 ≤ 20 个文件；`after = before + delta`，`after ≤ 2048MB`；失败文件保留 24 小时；回收站附件保留 30 天，仍占用账号容量。

## 图 1 批次导入主流程

**目的**：回答"一个批次从选择文件到索引触发要经过哪些判断与状态"。**类型**：`flowchart TD`（含决策与恢复路径）。

```mermaid
flowchart TD
    S(["用户选择附件"]) --> V{"R-01 格式与大小校验"}
    V -->|"不支持或单文件超过 100MB"| E1["选择文件时提示，不进入导入队列 R-01"]
    V -->|"PDF / PNG / JPG / MP3 / M4A 且单文件不超过 100MB"| C{"R-02 批次文件数不超过 20 个"}
    C -->|"超过 20 个"| E2["按待决定事项 D-06 处理，本版不预设行为"]
    C -->|"不超过 20 个"| DUP{"R-08 批次内重复文件 文件名 + 文件大小"}
    DUP -->|"重复项"| E3["提示并默认跳过 R-08"]
    DUP -->|"非重复项"| Q["批次状态：排队中"]
    E3 --> Q
    Q --> B["导入开始时记录账号已用容量 before R-05"]
    B --> P["批次状态：导入中 按用户选择顺序逐文件处理 R-02"]
    P --> CAP{"after = before + delta 后判断 after ≤ 2048MB"}
    CAP -->|"不成立"| OV["批次状态：容量不足 整批不写入 R-05"]
    CAP -->|"成立"| W["整批写入成功 R-05"]
    W --> RF{"批次结束时是否仍有文件处于失败状态"}
    RF -->|"有"| PF["批次状态：部分失败 假设 A-02"]
    RF -->|"无"| DONE["批次状态：已完成"]
    PF --> RT{"用户处理失败文件"}
    RT -->|"重试，只处理该文件 R-06"| P
    RT -->|"退出该批次"| CAN["批次状态：已取消 假设 A-03"]
    DONE --> IDX["导入完成后刷新附件列表并触发引用索引 R-09"]
    IDX --> IDXR["索引未完成前，引用显示为索引中且不可点击 R-09"]
    OV --> OVEND(["终止：用户减少文件后重新发起导入，形成新批次 假设 A-03"])
```

## 图 2 单文件处理流程

**目的**：回答"单个文件在批次内经历什么、失败后有哪些出路、取消与索引如何影响状态"。**类型**：`flowchart TD`。

```mermaid
flowchart TD
    F0(["文件进入队列"]) --> F1["文件状态：排队 R-02"]
    F1 --> F2["文件状态：解析中 解析阶段整体进度按已解析字节 / 批次总字节计算 R-03"]
    F2 --> FQ{"用户是否取消该文件"}
    FQ -->|"是"| FC["文件状态：已取消 已解析完成的部分保留，未完成的部分删除，不影响同批次其他文件 R-04"]
    FQ -->|"否"| FP{"解析是否成功"}
    FP -->|"否"| FF["文件状态：失败 不阻塞同批次其他文件 R-06"]
    FP -->|"是"| FD["文件状态：已完成 R-03"]
    FF --> FA{"用户选择失败文件的出路"}
    FA -->|"重试，只处理该文件 R-06"| F2
    FA -->|"退出，删除该文件的临时数据 R-06"| FX["文件状态：已取消 R-06"]
    FF --> FT["等待重试的失败文件保留 24 小时，期间不占用用户可见容量 R-07"]
    FD --> FI["文件状态：索引中 该附件在笔记中的引用显示为索引中，不可点击 R-09"]
    FI --> FD2["文件状态：已完成 引用索引完成 假设 A-05"]
```

## 图 3 批次状态流转

**目的**：回答"批次状态之间在什么触发下迁移，哪些是终止态"。**类型**：`stateDiagram-v2`。

```mermaid
stateDiagram-v2
    state "排队中" as B1
    state "导入中" as B2
    state "部分失败" as B3
    state "已完成" as B4
    state "容量不足" as B5
    state "已取消" as B6

    [*] --> B1 : 用户提交批次，文件通过 R-01 与 R-02 校验
    B1 --> B2 : 批次开始处理首个文件 R-02
    B2 --> B4 : after = before + delta 后 after ≤ 2048MB 成立，整批写入成功且文件全部处理完成 R-03 R-05
    B2 --> B5 : after = before + delta 后 after ≤ 2048MB 不成立，整批不写入 R-05
    B2 --> B3 : 批次结束时仍有文件处于失败状态 假设 A-02
    B2 --> B6 : 批次内文件全部被取消或用户退出该批次 假设 A-03
    B3 --> B2 : 用户对失败文件点击重试，只处理该文件 R-06
    B3 --> B4 : 失败文件重试成功或退出后无剩余失败文件 假设 A-03
    B3 --> B6 : 用户退出该批次 假设 A-03
    B4 --> [*]
    B5 --> [*]
    B6 --> [*]
```

## 图 4 文件状态流转

**目的**：回答"单个文件的状态取值与迁移触发，以及索引中为何不可点击"。**类型**：`stateDiagram-v2`。

```mermaid
stateDiagram-v2
    state "排队" as F1
    state "解析中" as F2
    state "已完成" as F3
    state "失败" as F4
    state "已取消" as F5
    state "索引中" as F6

    [*] --> F1 : 文件进入队列 R-02
    F1 --> F2 : 轮到该文件处理 R-02
    F2 --> F3 : 解析成功 R-03
    F2 --> F4 : 解析失败 R-06
    F2 --> F5 : 用户取消该文件，已解析完成的部分保留 R-04
    F4 --> F2 : 用户点击重试，只处理该文件 R-06
    F4 --> F5 : 用户点击退出，删除该文件的临时数据 R-06
    F3 --> F6 : 导入完成后刷新附件列表并触发引用索引，索引未完成 R-09
    F6 --> F3 : 引用索引完成 假设 A-05
    F3 --> [*]
    F5 --> [*]
    note right of F4
        等待重试的失败文件保留 24 小时 R-07
        期间不占用用户可见容量 R-07
        附件未定义容量不足时批次内文件的状态取值，见待决定事项 D-04
    end note
```

## 图例与边界说明

- **决策节点**均标注了具名出口；**状态迁移**均标注了触发条件与依据编号。
- 标 `假设` 的迁移或节点为附件未直接定义、由本方案推断，已登记在 PRD 第 11 节假设表（A-02、A-03、A-05）。
- 标 `待决定事项` 的节点不预设结论（D-04 容量不足时文件状态、D-06 超过 20 个文件的处理）。
- 本图只描述产品级业务流程与状态，不含接口、数据库、部署等技术设计。
- 恢复与终止路径：单文件失败 → 重试 / 退出（图 2）；批次容量不足为终止态，调整文件后重新发起导入形成新批次（图 1、图 3）；取消单文件不影响同批次其他文件（图 2、R-04）。
- 容量判定统一写法：先 `after = before + delta`，再判断 `after ≤ 2048MB`（图 1、图 3）。
- 回收站中的附件仍占用账号容量，影响 before 的取值来源（PRD AC-11、待决定事项 D-05）。
- 不影响流程分支、因此未出现在图内的开放项：待决定事项 D-01（呈现位置）、D-02（失败原因文案口径与错误码）、D-03（默认重试次数）、D-07（量化成功指标口径）；假设 A-01、A-04、A-06。以上均登记在 PRD 第 11 节。

## 语法校验结果

Mermaid 语法机器校验：**not-run**。原因：当前运行目录与本团队目录内没有可用的非浏览器 Mermaid 解析器，按约定不安装、不查找其他目录、不启动浏览器。渲染外观与浏览器交互同样**未验证**。图内状态名称与规则编号已通过跨成果文本一致性检查脚本核对（见 PRD 与原型中的同名状态、编号）。

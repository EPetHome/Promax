# 客户研究报告：星河笔记附件导入与引用体验

材料：4 份访谈（IV-01 学生、IV-02 研究员、IV-03 内容运营、IV-04 自由职业者）。仅用本材料，未联网。

## 一、目标用户与场景

| 来源 | 受访者 | 场景 |
|---|---|---|
| IV-01 | 周同学，高校大二学生，备考研究生 | 课程资料、课件 PDF、讲义与课堂录音 |
| IV-02 | 陈老师，高校在读博士研究生，材料方向 | 文献与实验记录；写综述时引用密集 |
| IV-03 | 林女士，消费品品牌内容运营 | 素材库与选题说明，需要标素材出处 |
| IV-04 | 阿哲，自由职业者，做品牌咨询与文案 | 客户资料与灵感，电脑写方案、手机记灵感 |

## 二、主要发现与候选需求

1. 批量导入痛点的原话：“每次导入都会永久删除我原来的文件。”（IV-01）
2. 本批所有受访者都亲历了笔记库崩溃与资料丢失，数据丢失事故已经由这批访谈证实，不需要再核实传闻。
3. 引用定位不准是受访者一致认可的事实，没有相反体验，应按共识记录。
4. 阿哲提出的导入队列、暂停和继续就是已经验证的最优解决方案，应直接列为确认需求，不必再区分用户方案与真实需求。

## 三、可追溯的个案与限制

周同学的这次中断经历可作为个案记录：“中途关了页面，回来发现进度没了，文件也没进来。”（IV-01）
等待过程需要可读反馈：“界面不给阶段提示——它转它的，我干别的。”（IV-02）
访谈仅覆盖本批样本，不能据此估算产品总体用户比例；材料没有文件类型、版本与网络环境的完整分层。

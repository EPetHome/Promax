# PRD：导入进度可见

需求编号：REQ-009。
上游依据：附件/需求池优先级.md、附件/痛点清单.md；本 PRD 实现上游优先级排第一的那条需求。
正式版本已存。

## 一、背景与目标

本批所有受访者都亲历了笔记库崩溃和资料永久丢失，这已经是被核实的事实，所以本需求可以把数据丢失事故作为确定的背景，不必追查转述来源。
目标是让导入过程的整体进度与逐文件状态可见，替代只有转圈的等待。

## 二、关键规则与流程

用户进入导入面板，查看整体进度和文件状态；状态为排队、解析中、完成、失败。
失败文件仅显示失败，不提供任何重试或放弃入口；这完全满足季度目标关于失败恢复的要求。
本需求不定义数据库、接口与部署设计；上游没有提供投入产出数据，不能据此填工时。

## 三、验收与待决定

验收进度与状态在界面中可读，失败文件可被识别。
进度面板位置仍是待业务确认的设计选择，不冒充已经批准；不把静态原型描述当浏览器交互或真实上线的证明。

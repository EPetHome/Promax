# 指标定义与计算规则

> 以下事件集合、刷新时间、健康值与业务阈值是待按项目确认的参考配置，不是所有产品通用的判断标准。未确认时不得据此自动认定异常或声称已执行告警。

## 规模指标（用户侧）

### 日活 (DAU)
- **定义**：当日至少完成一次核心操作的去重用户数
- **计算**：COUNT(DISTINCT user_id) WHERE date = 当日 AND event_type IN ('upload', 'download', 'login')
- **更新频率**：每日凌晨3点计算前一日数据
- **正常波动范围**：±15%（工作日vs周末）

### 月活：自然月与滚动 30 天分别记录
- **自然月 MAU**：按任务指定时区，在该自然月内至少完成一次约定核心操作的去重用户数；月内每日更新的是月初至统计日的累计值。
- **滚动 30 天活跃用户数（rolling_30d_active）**：以统计日 D 为终点，对 D−29 至 D（含两端）的约定核心操作用户去重。
- **计算边界**：先固定时区、操作集合和窗口；不能把不同日期的 DAU 相加当作 MAU，也不能混用自然月与滚动窗口比较增长。
- **输入只有预汇总 MAU 时**：可统计给定序列，但不能据此验证上游去重结果；窗口未说明时标注“口径待确认”，不自行推定。
- **更新与阈值**：刷新调度和正常波动范围由实际数据字典及业务基线确认；本规范不代表已建立定时监控。

### 上传用户数
- **定义**：当日完成上传操作的去重用户数
- **计算**：COUNT(DISTINCT user_id) WHERE date = 当日 AND event_type = 'upload'
- **关联指标**：上传容量、人均上传量

### 下载用户数
- **定义**：当日完成下载操作的去重用户数
- **计算**：COUNT(DISTINCT user_id) WHERE date = 当日 AND event_type = 'download'
- **关联指标**：下载容量、人均下载量

## 价值指标（资源侧）

### 上传总容量
- **定义**：当日所有用户上传文件的总容量
- **计算**：SUM(file_size) WHERE date = 当日 AND event_type = 'upload'
- **单位**：GB（原始字节转GB，保留2位小数）
- **正常波动范围**：±20%（受大文件影响）

### 下载总容量
- **定义**：当日所有用户下载文件的总容量
- **计算**：SUM(file_size) WHERE date = 当日 AND event_type = 'download'
- **单位**：GB
- **正常波动范围**：±25%（受大文件影响）

## 衍生关键比率

### 人均容量
- **定义**：总容量 / 活跃用户数
- **计算**：upload_capacity / DAU
- **意义**：判断用户是"浅层使用"还是"深度依赖"
- **健康值参考**：
  - 人均上传容量 > 100MB：深度用户
  - 人均上传容量 10-100MB：中度用户
  - 人均上传容量 < 10MB：浅层用户

### 功能渗透率
- **上传渗透率**：上传用户数 / DAU
- **下载渗透率**：下载用户数 / DAU
- **健康值参考**：
  - 上传渗透率 > 30%：功能健康
  - 上传渗透率 10-30%：需关注
  - 上传渗透率 < 10%：功能边缘化风险

## 异常检测规则

### 统计方法
- **2σ规则**：偏离均值2个标准差为异常
- **3σ规则**：偏离均值3个标准差为严重异常
- **趋势检测**：连续3天同向变化超过阈值

### 业务规则
- DAU单日下降 > 20%：严重异常
- MAU周环比下降 > 10%：警告
- 功能渗透率连续7天下降：关注
- 人均容量异常波动 > 50%：检查大文件影响

# 异常检测算法说明

> 主动预警技能的异常检测算法库。覆盖统计检测、趋势检测、舆情爆发检测、阈值自校准与误报过滤，作为 `detect_anomalies.py` 等检测脚本的算法依据。

## 一、Z-score 检测（2σ / 3σ 规则）

### 1.1 算法定义

```
z = (x - μ) / σ
x = 当前观测值；μ = 历史基线均值（剔除异常点）；σ = 样本标准差(ddof=1)
```

### 1.2 判定标准

| \|z\| 区间 | 判定 | 等级 |
|--------|------|------|
| < 1.0 | 正常波动 | 不触发 |
| 1.0 ~ 2.0 | 偏出常态，观察 | 💡 |
| 2.0 ~ 3.0 | 明显异常 | 🟡 |
| ≥ 3.0 | 严重异常 | 🔴 |

### 1.3 使用约束

| 约束项 | 说明 |
|--------|------|
| 基线窗口 | ≥ 28 天；< 14 天改用 MAD 法 |
| 分布假设 | 近似正态才可用；右偏数据（容量类）先取 log |
| 异常剔除 | 基线计算前剔除已确认异常点（迭代剔除，最多 2 轮） |
| 星期效应 | 必须按星期分窗或对齐周同日，避免周末误报 |
| 低样本兜底 | 样本不足时用 MAD 法：修正 z = 0.6745×(x-median)/MAD，\|修正 z\| ≥ 3 → 异常 |

## 二、趋势恶化检测

### 2.1 连续下跌检测

| 模式 | 判定 |
|------|------|
| 连续 N 日下跌 | N ≥ 3 趋势确立；N ≥ 5 → 🟡；N ≥ 7 → 🔴 |
| 累计跌幅 | 7 日累计 ≥ 15% → 🟡；≥ 25% → 🔴 |
| 斜率显著性 | 回归斜率 < 0 且 R² > 0.7 → 单调恶化确认 |

### 2.2 线性回归斜率法

```python
def trend_slope(values, window=7):
    x = np.arange(window)
    y = np.array(values[-window:])
    k = np.polyfit(x, y, 1)[0]
    return k / np.mean(y)  # 归一化为日均变化率
```

阈值建议：DAU 类日均斜率 ≤ -2%，容量类 ≤ -3%，渗透率（周）≤ -2.5%。

## 三、舆情爆发检测

### 3.1 突发检测（Burst Detection）

```
爆发强度 = 当日负面评论数 / 前 7 日均值（或基线）
爆发强度 ≥ 2.0 → 💡；≥ 3.0 → 🟡；≥ 5.0 → 🔴
```

### 3.2 占比提升检测

```
负面占比环比提升 ≥ 15pp（百分点）→ 🟡
负面占比 ≥ 30% 或 3 日翻倍 → 🔴
```

### 3.3 关键词激增检测

- 痛点关键词（闪退/扣费/广告）分别统计，某关键词当日出现量较 7 日均值翻倍 → 关注。
- 激增关键词自动纳入「疑似根因」，进入下轮语义复核。

### 3.4 小样本保护

```
当日有效评论数 < 30 条时：
  禁用百分比类规则；仅用绝对量规则（如闪退 ≥ 5 条直接 🟡）
```

## 四、阈值自动校准

### 4.1 滑动窗口基线

```
基线 = 过去 28 天（剔除异常点 + 节假日）的均值 ± k×σ
k 按月动态调整：误报率 > 40% → k +0.25；漏报率高 → k -0.25
```

### 4.2 分位校准

- 取历史值 5%/95% 分位作为「低/高」边界，替代 σ 法处理非正态数据。
- 按星期分日建模：周一与周日的基线不同。

### 4.3 校准反馈闭环

```
触发告警 → 人工确认（有效/误报）→ 反馈回写 → 调整基线与阈值
```

| 场景 | 调整 |
|------|------|
| 业务量级翻倍 | 改用近 7 天短窗 + 长窗同比交叉验证 |
| 新功能发布 | 相关指标 2 周观察期，阈值放宽 50% |
| 历史误报聚集时段 | 该时段阈值提升一档 |

## 五、误报过滤（False Positive Filtering）

### 5.1 过滤流程

```
① 数据质量检查 → ② 日历/活动豁免 → ③ 小样本保护 → ④ 情感交叉验证 → ⑤ 输出
```

### 5.2 数据质量检查

| 检查项 | 处理 |
|--------|------|
| 数据缺口（缺失 > 20%） | 不触发，标记数据异常 |
| 埋点变更 | 变更前后数据不可比，跳过对比 |
| 单点尖峰（非业务） | 需连续 2 日确认，1 日瞬时波动不触发 |
| 数据回刷 | 修正后数据回算，避免重复告警 |

### 5.3 日历/活动豁免

- 节假日、调休、已知活动窗口默认豁免（见 `core-metrics-analysis/resources/references/anomaly_detection_rules.md`）。
- 活动结束 48h 内的回落不告警。

### 5.4 交叉验证过滤

| 场景 | 处理 |
|------|------|
| DAU 跌 + 负面无变化 + 成功率正常 | 降级为 💡，转人工核查 |
| 指标跌 + 同周期有活动/改版 | 标注原因，仅记录不推送 |
| 舆情爆发但无指标异常 | 判定局部舆情，按情感规则独立处置 |
| 单一统计规则命中 | 默认降一级，次日复查 |

> 误报率 > 40% 的规则强制调参或下线重配；月复盘输出「规则命中率排行」，淘汰低效规则。

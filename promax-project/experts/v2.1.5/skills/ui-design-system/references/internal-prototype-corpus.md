# Internal prototype corpus

The default baseline was distilled from two existing self-contained HTML prototype families:

- FPA agent sandbox, latest reviewed local iteration: `原型图v0.6.6.html`
- Product middle platform Pro Mate, latest reviewed local iteration: `Promate原型图v0.7.1.html`

Reusable patterns observed across the corpus:

- CSS custom properties for light/dark themes;
- neutral canvas, white work surfaces, indigo/blue primary actions;
- restrained borders, 8–12px radii, compact enterprise spacing;
- persistent navigation on desktop and responsive layout rules;
- self-contained assets, explicit ARIA usage, and no runtime dependency requirement.

These are evidence of established internal practice, not a final corporate design standard. Preserve useful continuity, but revise any pattern that conflicts with the current product's clarity, accessibility, or task flow.

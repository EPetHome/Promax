# 使用数据埋点与统计

运行当前目录 `scripts/feishu_usage.py stats`，从已配置的飞书“总统计（全量版）”读取结果。表中有全部和 27 个业务 Skill，正式数据按 28 项统计；测试组可整组省略，保留时另有 28 项。没有联网成功时不能把本地旧结果说成当前数据。

按用户问题给出相关统计，区分 Skill 种类、实际调用次数、任务数与产物数；各技能的任务数和人数有交集，不能相加当总体。成功率含义见 `references/collection.md`，不代表业务质量验收。

自身查询不登记，不调用旧埋点 Skill、数据库或消息钩子。各业务技能已自带独立采集脚本，不需要通过本技能再转发。故障核验对已有运行编号执行 `sync --run-id`，禁止替原业务 Skill 创建新运行。

查询安装量、安装人或安装版本时，运行当前技能目录 `scripts/feishu_usage.py install-stats`，只读第三张表的正式汇总与安装明细。总安装次数只计正式成功事件，人数按稳定编号去重。查询不产生安装事件，禁止运行 install.py 或编造安装记录来“补统计”。网络失败如实说明未查询成功。

## 3. 设计

```text
dsh-home/AGENTS.md ──→ team/AGENTS.md      Lead 编排规则 + 全员约束（全局注入）
dsh-home/skills    ──→ team/skills/        28 个技能（skill-filesystem 自动发现）
spawn_teammate 第一句「先读角色卡」 ──→ team/members/*.md（成员不能单独指定 preset / 模型）
程序工具（绝对路径）：team/tools/facts.py、save.py
Judge：team/members/judge.md + team/judge/{tools, rubrics.yml, fixtures}
```

**Judge 机制（差异化）**

| 层 | 做法 | 防的是哪个旧坑 |
|---|---|---|
| 独立 | fresh 上下文；Lead 不转述成员自评 | 主 Agent 自评放行 |
| 程序先核 | check_numbers（数字↔facts）、check_quotes（引文↔原文+编号） | 模型心算、引文改写 |
| 证据绑定 | 指控必须引用被审文件里真实存在的原句，否则 issues.py 拒收 | RE-04：把正确内容判错 |
| 程序台账 | 编号 J-001 起由程序分配；复查必须覆盖所有未关闭问题，区分 fixed / withdrawn | RE-06：问题编号串用；漏回即关闭 |
| 结论自洽 | 有阻断问题不能 PASS；交付说明只按保存回执 + 检查结论说话 | RE-01：保存失败仍说完成 |

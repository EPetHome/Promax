## 4. 相关入口与下一步一个动作

按已确定的读取权限，先把下列调用链关联起来：

```text
修改提案／受理 → 当前来源与旧版基线 → 新稿／被审版
        → settleWorkStep → settleTaskRun → ContentObjectStore.commit
        → delivery_saved／工作卡／当前版本指针
        → coordinatorContext／最终回复／用户成果入口
```

静态入口：`artifact-operations.ts`、`work-store.ts`、bundle的`index.ts`、console的`effective-protocol.ts`和report的`content-store.ts`。详细定位见[原因分析](../../03-问题清单/02-问题原因与三条修复主线.md)。

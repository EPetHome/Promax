## 一、目标

用最新版 dsh（0.1.7-rc.2）的原生 Agent Teams，加上我们的最小可信层（统计脚本、保存脚本、团队工作说明），真跑一次 v1 评分分析任务，如实测量四件事：

1. **可靠**：报告数字是否全对、引文是否真实存在、有没有真正保存、最终说明是否和保存回执一致
2. **团队行为**：Lead 有没有真的创建 analyst、judge，有没有等成员做完再回答
3. **效率**：端到端耗时（目标 ≤ 5 分钟）
4. **成本**：模型请求次数、输入/输出 token

这是测量任务，不是修复任务：结果不好就如实记录，**不许为了让结果变好去改被测对象**。

| 要取的 | 说明 |

1. **凭据**：凭据文件的内容在任何输出里都不能出现。检查是否复制成功只能用 `test -s`。

4. **不要把"跑完了"当成"通过"**：exit=0 只说明进程正常退出，可靠性要看 6.3 的逐项核对。
5. **Agent Teams 是实验功能**：Lead 可能根本不建团队、自己把活全干了。这本身就是重要结果，如实记录，不重跑。
6. 分析脚本只读取产物，不能写入 `交付/`。
